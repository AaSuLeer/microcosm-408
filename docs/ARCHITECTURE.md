# v2 架构：状态驱动的双视图硬件实验

## 结构

- `src/engine.js`：确定性 CPU、汇编器、8 位运算、乘除法及原有 Cache/虚存算法。`tick` 返回新快照，不依赖 DOM。
- `src/labs.js`：每个实验的参数、总步骤、当前帧，以及内存布局与磁盘几何计算。
- `src/scene3d.js`：Three.js 实体几何、灯光、OrbitControls、射线拾取、屏幕标签、路径粒子和机械/移位动画。
- `src/scene2d.js`：各部件专属 SVG 原理图、线路拓扑、缩放平移、数据路径及磁盘运动。
- `src/app.js`：页面路由、参数表单、时间轴、播放控制、视图切换和 CPU 程序预演。

统一帧协议：`title / note / active / route / routes / values`。三维几何不自行执行算法，SVG 也不使用另一个版本的运算规则。同一实验的两个视图同时收到同一帧，只有当前可见视图渲染。

## 页面与状态

页面通过 hash 路由访问：system、memory、disk、io、cpu、multiplier、divider、adder、paging、flipflop。每页保存参数及步骤，返回时恢复；视图切换保留步骤和播放进度。刷新重置所有状态。用户输入只通过表单提交生效，防止半输入数值污染算法。

CPU 使用装载后的快照序列支持直接跳转回看，最多 1000 微步骤；HALT 后停止预演。六微步骤为教学时间粒度，不等于物理时钟。

## 教学硬件

### 内存

每颗芯片 4 字×4 位，位扩展为同片选两颗并联，共 4×8 位；字扩展为高地址位选择两组，共 8×4 位；同时扩展为两组两颗，共 8×8 位。容量守恒 `芯片数 × 16 = 总字数 × 总位宽`。

同组片选和组内地址共享，两个输出通路并行拼接成高/低 4 位，不能画成芯片间串行转发。4 拍突发锁定在 4 字边界，按 `(起始列 + 拍数) mod 4` 回绕。示例数据由地址确定，便于重复验证。芯片展开包括封装、单元/引线及字线位线；并非真实工艺建模。

### 磁盘

3 个盘片的上下 6 面，每面 8 条磁道，每磁道 12 扇区。`LBA=(柱面×6+盘面)×12+扇区`。柱面以透明圆柱联系同半径磁道。共用转轴使全部磁头联动，当前盘面磁头高亮。

`diskKinematics` 通过余弦定理求执行器角度，使磁头恰好位于目标半径；再计算目标扇区中心与磁头方位之间的旋转差。测试验证全部磁道与扇区的位置关系。3D 的盘片旋转与 SVG 扇区旋转取相同角度。

### DMA / I/O

演示 CPU 设置地址/长度、DREQ、HOLD、HLDA、DACK、4 字节 I/O→主存传输、释放及 IRQ。传输帧显示本拍数据和完成本拍后的下一目的地址/剩余计数。示例块传输期间 DMA 独占相关总线，不用 CPU 寄存器逐字节搬运。

查询/中断模式通过地址与读写信号选择接口寄存器：0xF0 读状态、写控制；0xF1 读写数据。地址/数据线分时复用未作为独立模式实现，不把这种端口映射与引脚分时复用混称。

### 运算与触发器

乘法每轮：检查 Q0→条件部分积加法→M 左移/Q 右移。完整无符号乘积保持 16 位。
除法每轮：移入被除数一位→9 位带符号试减→保留或恢复余数并置商位。
3D 位槽显示实际位值，移位阶段沿槽距平移；这种空间表达用于解释数据位置变化，不表示硬件部件机械移动。
D 触发器每次参数实验从 Q=0 开始，理想上升沿且 EN=1 时采样。

## 资源生命周期与交互

单个 WebGLRenderer 贯穿页面；换页释放旧场景的几何和材质，复用纹理和上下文。相机改变、帧更新或进度变化时才重绘，静止暂停不持续重画。模型变更保留同页相机，换页复位；结构展开不会强制丢失用户视角。

指针移动超过阈值视为拖动，避免旋转结束误触导航。标签可点击聚焦；可进入的模型带链接。WebGL 启动失败有可见错误与 SVG 回退，不以伪 3D 掩盖失败。

## 验证

`tests/engine.test.js`：穷举 8 位加减和乘除、真实取指示例、分支、自修改和非法指令、Cache/页表边界。
`tests/labs.test.js`：扩展容量和位拼接、突发回绕、DMA 计数、算术最终帧、全场景帧生成、磁盘 LBA/缺页、磁头几何和扇区对准。

完整 DRAM 电气时序、可编程流水线、组相联缓存、一致性、乱序、多核及浮点运算电路不在本次重构的实现范围，界面不宣称已覆盖。
